# Comprehensive Analysis and Visualization of UAE Stock Exchange Data

## Overview
This project provides a Python-based solution to analyze and visualize the UAE Stock Exchange's daily market data. The platform aims to make financial data more accessible and actionable for investors, analysts, policymakers, and researchers.

## Features
- **Daily Updates**: Access the latest market data updated daily.
- **Interactive Dashboards**: Visualize trends, sectoral performance, and price movements.
- **Data Filtering**: Focus on specific companies, sectors, or time periods.
- **User-Friendly Formats**: Download data in XLSX, CSV, or JSON formats.

## Requirements
To use this script, ensure you have the following installed:
- Python (>=3.7)
- pandas
- matplotlib
- seaborn

You can install the required libraries using pip:
bash
pip install pandas matplotlib seaborn


## Usage
1. Download the 'Daily Market Bulletin' dataset in CSV format.
2. Save the dataset in the same directory as this script.
3. Update the `dataset_path` variable in the script with the name of your downloaded dataset file.
4. Run the script using a Python interpreter.
5. View the generated visualizations for insights into market trends and sectoral performance.

## Example
1. **Visualize 52-week high and low prices for a specific company**:
   - The script filters data for 'ADNOC Logistics & Services' and plots its 52-week high and low prices over time.

2. **Analyze sectoral performance**:
   - The script calculates the average percentage change for each sector and generates a bar chart to display sectoral performance.
